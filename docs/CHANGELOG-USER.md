# What's New for Users

- Tools can now say who they are for. Toolhub lets a tool be tagged for editors, developers, readers, researchers, admins or organizers, and the tag drives the persona filters — but only 229 of the catalogue's 57,577 records carried one, and not a single gadget or user script did. The catalogue now reads that from what a tool's own page or source says.
- Only three of the six tags are ever added: editor, developer and reader. The other three were tried and dropped. Checked against the 210 tools a person had already tagged by hand, a guess of "researcher" was right about a third of the time, and "admin" and "organizer" no better — so those are left for a human to add rather than filled in wrongly.
- The three that are added were right for 149 of the 171 tools they were checked on. That is not perfect, and it is why every one of them carries the same small dagger the rest of the catalogue's machine-read metadata does, saying on hover where it came from.
- A tag a person set is never touched. These only ever fill a record that had nothing, which today is every gadget and every user script in the catalogue.
