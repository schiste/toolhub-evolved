# What's New for Users

- User scripts and gadgets now have a creation date, and it is the day their page was first saved. Registered tools have always carried the date their Toolhub record was created, and the wiki-sourced half of the directory carried nothing at all -- which made a gadget written in 2007 look newer than a tool registered last month, because the only date anyone could see was the day this catalogue happened to notice it. A wiki page knows exactly when it began: it is the timestamp on the first revision in its history, and that is now what the entry says.
- A gadget is dated by the oldest of its pages. Gadgets are declared as a set of scripts and stylesheets rather than a single file, and those pages are rarely all created on the same day; the date shown is the earliest first revision among them, which is when the gadget started existing rather than when it was last extended. If the declaration changes and an older page joins it, the date moves back to match; it never drifts forward on its own.
- Every entry already in the directory has been given its date, without anyone re-adding anything. The dates are filled in by the same hourly checks that already read these wikis, so the catalogue converges on its own over the next few runs. Pages the wiki cannot report a date for keep no date at all rather than a plausible-looking guess -- a blank is honest and a fabricated year is not.
- Tool pages say when the tool was created, and say plainly which date it is. The date sits with the other freshness markers, and hovering it spells out the source: for a user script or gadget, "first revision of this page on the wiki"; for a registered tool, "Toolhub catalog record created". The two are genuinely different facts and the page no longer asks anyone to guess which one they are reading.
- The statistics page counts user scripts and gadgets in its records-per-year chart, and lets you take them back out. The chart used to describe registered tools only, because those were the only entries with a date to plot; it now shows everything by default, with a choice of Everything, Registered tools, or User scripts and gadgets. Switching between them redraws nothing on the server -- all three series arrive together and the page just changes which one it is showing.
