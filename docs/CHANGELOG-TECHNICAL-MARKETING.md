# Technical and Marketing Notes

- `histogram()` in `views/statistics.js` takes an optional notes map keyed by row key, and the two date-based distributions pass `{ "2021": "Toolhub launched" }`. Keying by row rather than by position is the correctness property: `modifiedByYear` does not always reach back to 2021, and one tool type is literally named `2021`, so a note placed by index or by matching a label anywhere would attribute the launch to a year or a category it did not happen in. Three tests pin which rows carry it, and all four deliberate mutants of the placement logic were killed.
- The marker carries a `title` and a visually-hidden copy of the same text. A bare `title` on a span is not reliably announced, and the whole point of the note is that a reader who cannot hover would otherwise be shown a threefold anomaly with no explanation. It is sized off the row label rather than given a column, so an annotated chart still lines up with an unannotated one.
- Eight CSS rules that no shipped markup can match were removed from `base.css` and `organisms.css`: a mockup banner button, the account-records and toolpage-sync selectors left over from removed UI, two unresolved-entity variants, and a community-directory definitions list that shared a media-query selector with the still-live `.account-detail__facts`. The scan behind this ran repo-wide, not just over `public_html` -- restricted to the templates it would have declared all of `digests.css` dead, since those classes come from `proxy/backend/digests.py`.
- `views/account.js` and `views/parity.js` were deleted. Both were pure re-export barrels that the router never imported and no bundle shipped; only two test files kept them alive, which is backwards. Those tests now import the seven concrete modules directly, and the build's "reachable from no entry, worker or route" line no longer prints at all, confirming these were the last unreachable modules.
- `app.css` drops from 124,101 to 123,004 bytes raw and 18,946 to 18,817 gzipped, on top of the 2,402 gzipped bytes the route-stylesheet split removed in the previous release.
- `parity.js` was removed from the `views-rest+main` mutation shard without substituting another file, because adding a real view changes that shard's mutant count and could move the CI threshold. That scope is worth revisiting deliberately rather than as a side effect.
- Validation: all broker gates on the promoted tree, 1323 unit tests across 82 files, `i18n:check`, `lint:banana`, `dead:check`, `dup:check` and `budget` clean, and a Chrome render confirming the marker sits on the label's line with every row keeping the same height.
