# Technical and Marketing Notes

- `MediaWiki:Gadgets-definition` is now read as a manifest. The scan already located the line registering a gadget in order to learn which pages it consists of, then discarded the rest of it. `gadget_declaration()` returns the parsed entry with the line number and raw text it came from, and the analyzer emits one `accessRights` finding per declared `rights=` value, evidenced at that line. The page is classed `manifest` by title rather than through `MANIFEST_FILE_KINDS`, whose values select a dependency parser it must never reach; the resulting source weight is what lets a single sighting publish without a second file to corroborate it.
- Declared rights and observed calls dedupe into one finding. The vocabulary maps each MediaWiki right onto the same value slug `ACTION_RIGHTS` uses, so a gadget that declares `rollback` and is also seen calling it produces one row carrying both pieces of evidence. The declaration is scanned after the source files, so the category an observed call assigned survives — `_put` sets a category once, on first insertion.
- Declaration-only rights stay outside the write categories. `rights=` states an audience gate, not an action, so every declared right is reported under `restricted` at confidence 0.9, just under an observed `action=` call's 0.94. That keeps `writeActionsDetected` — and the unauthenticated-write scoring penalty it drives — settled by code that was actually read.
- The vocabulary is measured, not assumed. Across the definition pages of en.wikipedia (113 gadgets), Commons (142), de.wikipedia (62), fr.wikipedia (95) and Wikidata (76) — 488 entries — 69 declare `rights=`, naming exactly twenty-one distinct rights. Five wikis are not every wiki, so a right outside the table is reported under its own name rather than dropped.
- `default` travels as reach, not permission. It lands on the `wikiPage` row as `gadgetDefault` and surfaces as one neutral permission-clarity signal, contributing nothing to the score. The key is absent rather than false when no definition line was read, so "not measured" stays distinguishable from "declared opt-in".
- Archived tools left the default search population. `catalog_read` selects `catalog_facets.default_population()` unless `include_archived` is set, and that parameter also forces real facet counting because the cached aggregate is built over the default population only.
- Feature-status artifacts were regenerated against what the analyzer does now. The source-analysis entry listed a bucket set two releases stale; automatic repository and on-wiki analysis, the worker behind the repository-analysis provenance label, had no entry at all.
