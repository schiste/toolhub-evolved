# Technical Release Notes

- Lifting the wiki page ceiling to 1 MiB last release admitted build output alongside the large hand-written gadgets it was meant for. `_is_build_output` now drops a generated page from the set in `_wiki_files`, before the analyzer ever sees it. A bundle's dependencies are the libraries vendored into it rather than the tool's own, and a suggestion drawn from those fills whatever Toolhub field is empty and is scored as if it had been measured -- reading nothing is recoverable, publishing a wrong dependency list under the tool's name is not. The largest such page found on en.wikipedia is 658 KiB on one 672,615-character line.
- Line length is the signal that does the work, and it needs no tuning because the two classes do not overlap. Measured over the largest pages on the eight catalogued wikis, build output runs to 672k, 795k and 1.1M characters on a single line, while the longest line in a hand-written gadget is 2,938. `MAX_SOURCE_LINE_CHARS = 50_000` sits in the empty space between the two rather than splitting a continuum.
- The source-map annotation is the builder's own statement that a file came from other files, and it is the honest signal, but it matches nothing in the catalogue today: a `.map` file has nowhere to live on a wiki, so pipelines aimed at one turn maps off. It is kept for the pages that will carry it, and anchored to the start of a line -- the one page in these wikis holding the string holds it mid-line inside a `.concat()`, loader runtime writing a map for a stylesheet it injects. Unanchored it would exclude any gadget whose code merely talks about source maps.
- Checked against the pages themselves rather than against fixtures alone. The classifier agrees with a hand classification on all 8 of the largest pages across six wikis, and over 192 of the 219 catalogued wiki tools, resolved through `_wiki_revisions`, it removes no page from any of them and empties no page set. Both positive tests fail with the filter removed, and the mention test fails with the anchor removed.
