# Technical and Marketing Notes

- `_catalog_totals` chose `CatalogToolProjection.effective_record` whenever the row had one and fell back to `CanonicalToolCache.record` only when it did not. That is a substitution, and the projection is a partial record: it carries only the fields the projection lane computes. Measured against production, it held `title` for 54,937 rows and `description` for 9,554, and `modified_date`, `created_date` and `author` for none of its 57,290. The canonical layer held those three for 52,565, 52,583 and 46,714 tools.
- The symptom was four counters collapsing to the same number. `modifiedByYear` and `createdByYear` each reported 53,189 of 53,190 tools as "Date unavailable", and `listedAuthors` and `coreMetadataComplete` each counted 1. That 1 is diagnostic rather than incidental: with 57,290 projection rows covering 53,190 canonical rows, it is the single tool with no projection row to lose its fields to.
- The fix layers instead of replacing: `record = {**canonical, **overlay}`. The overlay still wins wherever it carries a value, a deliberate blank included, so the enrichment the substitution was introduced for is preserved — the 2,583 inferred descriptions that the earlier canonical-only reading could never move. What it stops doing is treating silence in the overlay as an assertion of absence.
- `people_index._compact_profile_tool` already combined the two layers exactly this way, so the merge is the established pattern in this codebase and statistics was the outlier. The lens split still reads `CanonicalToolCache.source`, and the join stays outer, so a tool the projection has not reached is counted from its canonical record as before.
- The wiki last-edit dates published as `modified_date` in the previous release were correctly written and entirely invisible on this page, which is worth naming: a field can be populated, verified in the database, and still absent from every number a reader sees, if a later layer is read in its place.
- Validation: 35 passed across `tests/proxy/test_catalog_statistics.py` and `test_statistics_refresh.py`. The regression test was checked by mutation rather than assumed — it fails against the previous code and passes against this one, and it asserts both halves on one tool, so a fix that restored the canonical fields by dropping the overlay would not pass it. All six broker gates green, including the full `pytest-proxy` suite.
