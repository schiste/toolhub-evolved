# Technical and Marketing Notes

- Two replica gaps closed, both the same failure with different blast radii. The local replica is keyed on the exact upstream URL including its query string, and a miss is a hard 503 by design -- request-time fetch-through is what the architecture forbids -- so any coverage has to come from the prewarmer. `/api/auditlogs/` was never on the hot list at all, and `views/audit.js` caught the 503 into `{results: []}`, which is how a feed reads as empty for months without anyone reporting an outage. Guard tests now parse the `page_size` literal straight out of the view and assert the prewarmer keeps that exact URL hot, so the two cannot drift apart silently again.
- Per-tool revision history could not be fixed by one more hot entry: the key space is unbounded. It is warmed instead for the tools currently on `/recent`, capped at 25, which follows the way a history is actually reached -- feed, tool, history -- at a cost flat in catalog size, about 1.7 upstream reads a minute. The tail cannot be covered by any prewarm, so `views/tool.js` now separates "no revisions" from "could not read revisions" rather than asserting the first when only the second is true.
- Populating the audit cache exposed a second defect that would have shipped as a privacy regression. `app.py` filters withheld rows through `sanitize_public_api_payload`, but the `/v1/catalog` compatibility branch reads the same store and applied no filter -- harmless only while that cache was permanently empty. It now makes the same decision, so which door a reader arrives through no longer decides what they see. The filter keys off the URL, so every non-activity surface still passes through byte for byte, and a test asserts exactly that.
- Shared bundles are now grouped by the exact set of routes that depend on them instead of being hoisted into one 75 KB `common.js`, 42% of which served two routes out of 31. Groups under 8 KB stay pooled, where a separate request would cost more than the bytes. Lazy payload for `/statistics`: 81.7 KB to 22.7 KB gzipped.
- The six global stylesheets are concatenated at build time, in cascade order, into one `/styles/app.css` -- 21,364 B gzipped against 24,263 for the six, and five fewer responses on a capped connection. The layer list is read out of the shell rather than hardcoded, and the layers are no longer emitted separately so the same rules cannot arrive under two URLs.
- `index.html` carries a route-hints table for the four routes whose first paint waits on one slow read (1.5s to first byte on `/recent`, 1.4s on `/workers`), starts that read from the inline script, and preloads the bundles the build resolved for the view. `api.js` claims the pending response at its transport seam, so caching, retry, timing and stale-revalidate decisions above it are untouched. A test drives the real path-to-fetch chain and fails if a hint stops matching -- a stale hint does not break a page, it just quietly stops helping.
- Validation across the release: 3069 proxy tests, 1314 unit tests, and all eight broker gates on the promoted tree. Each new guard was checked by reverting its half of the fix and confirming the test fails.
