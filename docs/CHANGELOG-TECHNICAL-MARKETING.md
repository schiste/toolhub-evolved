# Technical Release Notes

- Adds a durable digest domain over captured official tool-creation events, immutable edition/tool snapshots, publication state, channel subscriptions, and a restart-safe delivery outbox. UTC day, ISO-week, and calendar-month boundaries are deterministic, generation is idempotent, missed closed periods recover automatically, empty periods are suppressed, and idempotent MariaDB migration widens complete rendered bodies to `MEDIUMTEXT`.
- Integrates LiftWing's public OpenAI-compatible `llm-qwen36-27b` chat-completions endpoint with strict Wikimedia host/path/model validation, contact-bearing user-agent headers, bounded timeouts and citation-only payloads, period-wide candidate sampling for busy weekly and monthly editions, Qwen reasoning-tag removal, schema validation, unique supplied-title normalization to canonical tool ids, exact full-field or whitespace-normalized verbatim excerpt evidence checks, and an audited deterministic fallback with sanitized failure details. Daily requests and responses cover every supplied tool exactly once; weekly and monthly responses select exactly `min(total, 5)` tools; omissions, duplicates, ambiguous or invented identifiers, paraphrases, and trivial fragments remain fail-closed. A database-free live preflight exercises production facts through inference, validation, and rendering before deployment.
- Publishes canonical edition pages and the archive tree on Meta through a bearer-authenticated Wikimedia Action API client that restricts destinations, verifies the configured service-account identity, bounds responses, refreshes CSRF tokens, and classifies permanent recipient failures. The same client appends talk-page sections and calls `emailuser` without adding SMTP infrastructure.
- Exposes public edition APIs, local blog routes, per-cadence RSS feeds, authenticated subscription/status APIs, seven-day confirmation links, lifetime unsubscribe links, stable Wikimedia identity checks, bounded delivery retries, and per-subscription suspension without cross-channel impact.
- Adds a compact responsive archive and human-scale edition layout, summary-only archive payloads, accessible subscription controls, localized English strings with translator documentation, immutable permalink and feed discovery metadata, and regression coverage for routes, rendering, confirmation, delivery, RSS, outbound guards, identity trust, and UTC period behavior.
- Schedules publication at 06:15 UTC, delivery every five minutes, and an hourly audit. Job locks reclaim at twice each timeout; audit failures cover missing configuration, recent Qwen fallback, overdue generation, Meta/archive failure, exhausted delivery, and stale validated or queued work.
- Supports operator-selected historical editions through an internal website-only publication state excluded from Meta, RSS, and subscriber delivery, with no preview or automatic selector. Editions freeze canonical author labels and current verified author/maintainer identities, expose only grounded name arrays to Qwen, and render Toolhub, direct-tool, author-index, and stable-person links deterministically across every output; unverified or expired edges and unsafe identity/link data are excluded before the immutable snapshot is rendered.
- Keeps OAuth account and encrypted-grant persistence atomic and independent from the derived people index. Transient database locks retry or return a controlled login error rather than HTTP 500, while identity reconciliation closes its read session before remote lookups and reconnects for the write phase; the hourly identity-only worker likewise completes remote registry requests before acquiring shared people/user row locks. Complete LDAP generations distinguish immutable `uidNumber`, Developer account `cn`, and Unix shell `uid`; SUL binding remains authoritative, while an unbound account can be verified only by an exact cross-provider handle plus independently verified same-tool evidence. Corroboration indexes include both person-bound relationships and active verified unresolved-attribution rows, while excluding withdrawn, expired, and self-generated LDAP projections. Bare handle matches remain candidates, proof records immutable account and shared-tool evidence, and preloaded indexes avoid per-account reconciliation queries. Toolsadmin labels remain attribution unless independently corroborated, legacy label proofs are retired idempotently, unmapped memberships cannot invent catalog tools, and multi-account people are read without cardinality failures. Projection policies are content-addressed to force rebuilds after algorithm changes, deep recent-event backlogs checkpoint exact markers instead of failing at 20 pages, and complete catalog snapshots retry bounded upstream count races without pruning from an inconsistent generation. Projection refresh invokes the incremental recent-change and rolling-reconciliation path; only the separately scheduled twice-monthly integrity job builds a complete generation. Full source audits serialize source-evidence writers and commit bounded retryable batches instead of holding one catalog-wide transaction, while expected refresh overlaps persist as deferred work rather than false failures. Card summaries retain a compact ambiguity-safe projection of every public author/maintainer identity and observed label while excluding full profiles, and statistics expose distinct tool, person, relationship, verification-transition, identity-only, stale, and expiry units. The private My tools payload preserves many-to-many project/account bindings, while a schema-driven browser editor and repository-shipped agent skill generate, validate, copy, and download complete Toolinfo 1.2.2 records without conflating maintainers, authors, core metadata, or API-owned annotations.
