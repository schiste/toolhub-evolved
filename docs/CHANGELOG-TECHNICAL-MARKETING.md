# Technical Release Notes

- `userscript_census.enumerate_titles` short-circuits at `SEARCH_OFFSET_CAP` (10,000) and returns a single `SEARCH_PAGE_SIZE` page with `complete=False`, so Meta's javascript census held ~500 of 25,354 titles. The remedy the module's own docstring prescribed does not exist: probed live against Meta, one negated `prefix:` clause partitions the index exactly, a second is silently dropped, and two positive ones return zero. CirrusSearch cannot be made to prove it named everything.
- New `backend.userscript_enumeration` prefers one indexed replica read -- `page_namespace = 2 AND page_content_model IN ('javascript','css') ORDER BY page_id` -- and falls back to the search road on any failure, an empty result included, because an enumeration that names nothing while calling itself complete is the one answer that would tombstone an entire wiki. Measured from Toolforge: 155,561 enwiki rows in 13.2s. `page_id` order is creation order, which is what `discovery_rank` wants, for free.
- The replica road costs one `meta=siteinfo` request per wiki, and refuses to proceed without it. The replica stores `page_title` with no namespace and with underscores; the API answers frwiki titles as `Utilisateur:`, not `User:`. Ranks, revision-skipping and tombstoning all key on the title, so requesting under the canonical prefix would have zeroed every rank and tombstoned every stored frwiki page on the first sweep.
- `sweep()` takes a `limit`, each wiki carries a `sweep_cursor`, and `ingest()` takes a `rank_offset` so a slice records absolute ranks instead of renumbering from zero -- the collapse breaks its ties on that order, so a slice numbered from zero would report the ten-thousandth page ever created as the first. Only the run that reaches the end tombstones missing pages or counts as a completed sweep.
- A cursor indexes one enumeration and means nothing against a different one, so it is dropped when the enumeration is incomplete or points past the end. Both cases restart from zero: that costs a pass and cannot silently skip pages.
- enwiki joins at `USERSCRIPT_LIMIT=2000` -- 100 content requests per run at `CONTENT_BATCH` 20, about 78 runs for a first pass. It needs no `LOCAL_LOADERS` entry, the only table keyed by wiki: its `MediaWiki:Common.js`, read 2026-08-22, defines no load verb at all, aliasing `addPortletLink` and honouring `?withJS=`/`?withCSS=`, neither of which a user script can call.
