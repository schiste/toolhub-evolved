# Technical and Marketing Notes

- `organisms.css` was 97 KB of the merged `app.css` that every page blocks on, and roughly a quarter of it matched classes exactly one view can produce. Those 200 rules now live in ten route-owned stylesheets that the owning view declares in its `styles` array. `app.css` drops from 142,847 to 124,101 bytes raw and 21,348 to 18,946 gzipped, so 2,402 gzipped bytes leave every page in the app.
- The split is only safe under conditions that fail silently, so each one is now a test. `tests/unit/route-styles.test.mjs` asserts that no other view can produce a route sheet's classes, that no selector is duplicated between a route sheet and the global bundle, and that the router's prefetch map, each view's own `STYLESHEET` const, and the shell's route hints all name the same URL. Each assertion was checked by breaking it deliberately and confirming the failure.
- The cascade is the real hazard, and one rule was caught by it. A route sheet loads after `app.css`, so it also loads after `templates.css` -- any equal-specificity tie a moved rule used to lose, it wins. `.people-page__results-head` had been losing `align-items` to `.section-head` for as long as both existed; moving it would have revived a dead rule and shifted the accounts directory's results header. It stayed in `organisms.css`, and a test now fails on the next rule in that position.
- Verification was differential rather than declarative: the pre-split tree and the post-split tree were served side by side and compared in Chrome on computed style, across 11 routes and 581 class combinations the owning views actually emit. Identical, except a spinner caught mid-animation. Rule-level conservation over the old file: 766 rules in, 566 left plus 200 moved, none missing and none duplicated.
- Prefetch is what keeps the split perf-positive. Dispatch awaits a view's stylesheets before committing HTML, so a sheet discovered only after its module resolved would have traded bytes for a serial round-trip on that route's first paint. `loadRouteModule` now starts the sheet as the import begins, and `loadRouteStyle` memoizes, so the later await resolves against a request already in flight.
- The route-hints table in the shell gained a `css` field for the three hinted routes that own a sheet, preloaded from the same inline script that already starts their main read. The URL is deliberately unversioned and byte-identical to the one the router requests -- a preload for a different URL is a second fetch, not a head start -- and the build fails if a hint names a stylesheet that does not exist.
- Validation: all eight broker gates on the promoted tree, 1319 unit tests, 3069 proxy tests, and a rebuilt `dist/` confirming the hint table and the merged bundle. The CSP hash for the edited inline script was recomputed and is asserted by `tests/proxy/test_app.py`.
