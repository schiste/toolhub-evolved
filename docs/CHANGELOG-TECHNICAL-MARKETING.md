# Technical and Marketing Notes

- `audiences` is the first inferred field with a closed vocabulary, which is the only reason it could be shipped at all. Six values, spelled as `routing.js` spells them for the persona facets and as all 229 human-labelled records use them, make this a classification rather than a generation — so a wrong answer is a wrong _choice_, and agreement with the existing labels could be counted per value instead of argued about.
- Measured on 2026-09-05 against the 210 human-labelled tools carrying a description and at most three audiences: editor 0.91 (72/79 published labels correct), developer 0.86 (49/57), reader 0.80 (28/35), researcher 0.36 (16/45), admin 0.38 (9/24), organizer 0.42 (5/12). The aggregate 0.73 hides that split completely; publishing only the first three is 149/171 = 0.87.
- The whole vocabulary is still offered in the prompt even though half of it is discarded. Asked with only the three publishable values, the model pushes a research or moderation tool onto the nearest survivor rather than declining, and developer falls to 0.76 and reader to 0.74. The unpublished values earn their place by giving those tools somewhere else to go — an assumption that per-value precision would simply carry over was measured and turned out false.
- `_audiences` filters twice and the order carries meaning. A value outside the vocabulary is the model ignoring the list it was handed, and is reported as a malformed answer. A value inside it but outside `PUBLISHABLE_AUDIENCES` is a correct reading this catalogue declines to publish, and is dropped with no reason recorded — recording one would file a good answer as a fault and put the row into the rejection backfill to be re-asked.
- This is the field the module header records the model getting wrong at a self-reported 0.9, and the header now says why it is asked for again. Nothing about the model changed; the question did. That earlier reading came from a prompt asking twelve fields at once and taking the model's word for the result, against six named choices scored on 210 records.
- The projection needed no change. `audiences` is already in `LIST_FIELDS`, so `FILL_ONLY_SOURCES` already stops an inferred value extending a list somebody else wrote, and the gap is the entire population: 11,012 gadgets and 40,254 user scripts hold none. `source-mark` already marks by field and lane.
- Three existing tests asserted exact `detail` strings and now legitimately name the third field. They were updated rather than loosened, and one — that an answer accepted whole stores no copy of its own words — needed a real reply from the current prompt, since every other fixture predates `audiences` and is properly missing it. That reply was captured from Lift Wing rather than composed.
- Validation: 3,660 proxy tests with `inference_enrichment` at 100% statement and branch coverage, `ruff check`/`format` and cspell clean. The new work appears as `inference-enrichment` sweeps the corpus; the gadget lane finished its keywords on 2026-09-04 and re-asks only where a description changed, so audiences arrive with the next pass over each record.
